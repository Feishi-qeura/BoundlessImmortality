无极仙道 · Windows 完整本机玩法 v1.4 · 竖屏 UI 2026-10-23

启动：双击 Start-Wuling.cmd。请先完整解压，不能直接在 ZIP 内运行。
默认以 540×960 竖屏窗口启动，可拖动窗口边缘调整大小，界面自动重排。
首次运行如系统缺少 VC++ 运行库，请安装 Engine/Extras/Redist/en-us/vc_redist.x64.exe。
不需要安装 Unreal Editor 或 Python。本包包含独立 Python 3.12 标准库及许可证。

进入游戏后：“仙途 → 武灵历练”可创建武灵和开始历练；“玩法功能”包含制作、来源、
突破天劫、装备功法、建设、活动、竞采、商店及寄售，“组织与记录”包含成员和订单。
模拟观众可在 GM 工具中发送“加入”“护阵”“破障”“共修”“助力”。首次开始不赠送测试资产。
“世界历练”中前三个区域可进入准备：青云山沿用护阵；落霞谷第一阶段需点击“选择采药路线”
解除药田封印，观众也可发送“路线采集”；玄铁岭第二阶段需点击“破障”或由观众发送“破障”，
开启8秒弱点窗口后飞剑才能伤害障碍。操作均免费，三地区域使用同一阶段奖励预算。
当前三地区域共用已有场景及通用目标模型作为美术占位；后续可替换区域专用素材。
既有场景问题：部分石台和植被在打包版中呈灰褐色，源于场景材质的实例化网格使用标记；本轮 UI 重构未修改这些场景材质。
没有资源的效果先使用现有通用图标、图集及目标模型；未开放的后续章节明确显示未开放。

存档：%LOCALAPPDATA%\BoundlessImmortality\LocalV14\default
日志：上述目录内 launcher.log、authority.log 及 Game 下的 UE 日志。
关闭游戏会同时停止本次启动的本机服务；存档、事务收据和待确认请求保留。
不要删除 prototype.sqlite3、其 WAL/SHM、identity.json 或 Game 内 outbox 来解决连接问题。
同一 profile 只能启动一次。失败时查看日志，规则不匹配请保留原档，不要修改数据库哈希。
本版新增区域参数已进入规则哈希；早期原型存档不自动迁移，也不能通过改哈希继续写入。

本机双主播验收：先启动第一实例，在其 launcher.log 找到 http://127.0.0.1:端口，运行：
Start-Wuling.cmd --profile second --connect http://127.0.0.1:端口
第二实例使用独立身份和存档，但连接第一实例服务。需由第一实例最后退出。
相同应用的多主播只能使用同一权威服务进行匹配；自动开启独立服务的两个实例不会相遇。

配置：完整玩法使用 Win64 Development，启动参数显式开启隔离本机模拟。
直接打开 BoundlessImmortality.exe 将进入旧默认模式；完整玩法请使用 Start-Wuling.cmd。
Shipping 中模拟身份仍被禁用。本包不含正式平台身份、真实付费、生产服务或平台审核凭证。
本机可运行与可打包，不代表抖音或其他平台已批准公开发布。
