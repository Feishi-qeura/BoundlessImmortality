# v1.4 策划功能实施计划（跳过 UI 视觉重构）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans after user review, or superpowers:subagent-driven-development only if the user explicitly selects delegation. Steps use checkbox (`- [ ]`) syntax for tracking. This document does not authorize agents or production deployment.

**Goal:** 将 v1.4 策划中的玩法、经济、组织和活动接入现有 UE 工程，保留功能页面和真实数据接入，跳过独立 UI 开发规范的视觉重构。

**Architecture:** 增量扩展现有 `UWulingPrototypeSubsystem`，以本机 Python/SQLite 服务作为新增规则的唯一权威。UE 发命令、接快照并播放既有剑灵表现；个人财产、公库、成长和旧礼物分别记账。先打通十分钟历练闭环，再按独立子计划增加物品/天劫、竞采/活动和功能页面。

**Tech Stack:** Unreal Engine 5.8，C++、UMG、Python 标准库、SQLite。首轮不引入外部服务、账户或依赖。

**Spec:** `docs/design/2026-10-21-wuling-resource-v1.4/README.md`、01–10、14–16及 `tables/`；11–13只采用功能、数据和交互验收要求。独立 `2026-10-21-ink-ui-standard-v1` 不在实施范围。

**Status:** 用户于2026-10-21以“开始”批准当前会话实施。2026-10-22已交付本机 prototype_full 运行实现、UE功能接入和验证证据；没有执行独立UI视觉重构。完整原始专项/状态矩阵尚未逐项验收，具体未验证项见 [交付报告](../../2026-10-22-wuling-v14-implementation.md) 和 `Saved/Codex/GameplayPlan20261021/acceptance-report.json`，不宣称全部用例通过。

## Global Constraints

- 用户已确认“保留功能页面与数据接入，跳过视觉重构”。不以旧 UI 首段视觉验收为本轮玩法实施前置条件；旧 UI 计划保持原文件不覆盖。
- 不改变当前相机、地图框架、手工 WBP 默认配置、本命剑和已配置礼物映射。不得用历史备份覆盖当前文件。
- 策划优先级：用户本轮范围 → v1.4 的15/16和扩展配置 → 14及launch配置 → 基础01–10。旧小阶成本、观众自动突破与旧礼物继续保留。
- 新规则运行版本标识定为 `wuling-prototype-v1.4.0`；manifest同时保存基础表版本、物品版本、开服版本及规范化配置 SHA256，不通过篡改原表的design_version伪造统一版本。
- `prototype_full`、应用、身份、成长窗口、规则版本隔离；数据库默认 `Saved/WulingPrototype/v1.4/prototype.sqlite3`。旧JSON档不自动导入，新规则禁止读写旧权益文件。
- 新经济服务仅监听 `127.0.0.1`。模拟身份需要双开发标记，不能用于生产登录；`douyin_release_candidate` 在服务和客户端均关闭受限功能，manifest缺失即拒绝。
- 钱和物数量用整数；时间由服务端推进，UTC持久化；签到用香港自然日，开服榜用活动相对日。事务收据不得因资产过期而删除。
- 旧礼物为 `legacy_preserve`；不新增真实价格、礼物ID、官方ACK或正式身份适配，不静默切换候选倍率。
- 每个子计划必须有服务事务测试、UE接入验证及未验证项报告。配置验证、HTTP服务测试、UE编译、渲染PIE、双进程、设备和正式平台分别记录。
- 当前工作目录没有Git元数据：使用逐文件备份、SHA256和变更清单替代提交；不初始化Git，不假称创建提交。

## Review Focus

1. 同一命令提交成功后丢回包、旧expected_version重试：先查原收据，返回原结果，不再扣料或抽签；测试属于基础计划T1、天劫T5。
2. 同一观众从A房切至B房后A房继续心跳：只能保留一个收益会话，旧代次失效；基础T2、功能接入T1。
3. 预留材料在服务故障期间过期：解除原预留并按原期限归档，不退款复制、不重新抽签；物品T1、天劫T5。
4. 相对活动日与香港自然日错位：只允许7个活动桶；基础T2和竞采活动T4分别验证。
5. 天劫结束时其他警戒或礼物状态发生变化：仅释放本次attempt预警，再计算当前状态；功能接入T3验证全部清理路径。
