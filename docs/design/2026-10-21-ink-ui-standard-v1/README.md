## 本次明确的变化

底部原有“角色、背包、排行、菜单”之间增加一个更突出的“修炼”动作，共五项；修炼是动作，不新建一套重复修炼页面。顶部仍以活动、签到、仙途三个入口为主。图中门派、法宝、聊天、摇杆、任务、80级等不构成实现授权或业务存在证明。新顶部图标样式可配置，不能以排列好看为由重复入口。

旧素材清单写明某轮不实施随机抽奖；本轮用户明确要求转盘 UI，因此本规范补全该视觉和交互设计。正式付费/随机业务仍需真实规则、奖池和服务端能力，缺失时关闭正式入口并提供明确的开发预览，不能用客户端随机冒充已到账。
