# Consignment Market · concept prompt

Create one full portrait mobile UI composition concept for a Chinese cultivation game's consignment market. A fresh responsive market page: pine-ink header, server-provided market state, compact market/owned filter display, scrollable real-listing rows with blank item/price/status placeholders, selected listing detail, and a separated owner listing editor showing user-entered quantity and unit-price fields without any default values. Clearly distinguish browse, create listing, buy listing and pending service states. Shared ink, jade and warm ivory, restrained gold; labels “寄售”, “范围待同步”, “商品详情”, “数量”, “单价”, “发布”, “待同步”. No fabricated item, listing, price, fee, min/max rule, proceeds, platform payment or order state. Composition only; data and text remain live UMG.
