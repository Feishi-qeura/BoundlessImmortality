## 9-slice and state rules

All copied approved art uses the upstream `full` slice contract; none of the selected images is stretched as a nine-slice. This is a measured upstream contract choice, not missing metadata. Repeated panels/buttons in breakthrough and tribulation use existing native Slate surfaces until a separately authored frame is reviewed. Candidate page screenshots are RGB full-page references and are not component assets. The new material slot atom is a UMG widget, not a nine-slice image; its optional frame is pending-export. Selected/disabled state is controlled by `SetSelectionEnabled` and authority-supplied `bCanSelect`, not by guessed business state.
