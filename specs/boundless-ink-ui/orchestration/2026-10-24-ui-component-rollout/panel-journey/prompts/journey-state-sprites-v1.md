# Journey 状态组件雪碧图 v1

为中国修仙水墨手游制作一张单独的游戏 UI 组件素材雪碧图，透明背景，画布 1536×1024。只出现 11 个互不接触、周围有明显安全空隙的独立图形，按从左到右、从上到下固定顺序排成自然的 4/4/3 网格；不画网格线、编号、文字、符号字符、水印、说明箭头或任何完整页面。

第一行：3个世界区域地图节点徽章，外轮廓尺寸一致：已探索（青玉小勾记嵌在山形/圆形徽章）、可前往（金色路线圆点加细描边）、未开放（墨灰封印锁）。仅图形，不含文字。
第二行：4个资源地图 pin 图标，尺寸轮廓一致：免费历练采集（青玉叶片）、临时点（蓝灰沙漏）、竞争开放（旧金交错双剑或旗）、过期不可用（灰墨止用环），四种形状与颜色都明显不同，不含文字。
第三行：4枚每日一签签运小印章，尺寸轮廓一致：大吉（旧金祥云/太阳）、吉（青玉如意叶）、平（蓝灰平衡圆环）、凶（赭红云纹避让符）；只做装饰符号，不生成汉字、数字或文字。

全套采用已确认的水墨UI方向：温润玉石/墨玉/旧金/灰青/少量赭红，宣纸游戏UI插画质感，细金线与清晰剪影，小尺寸依然容易辨认，柔和左上光，完整边缘与适度留白，适合逐个合成到地图和签到 WidgetTree。Alpha 必须是真实透明；不可用白色、米色或棋盘格伪装透明背景。每个组件边缘清晰、没有投影溢出到相邻组件。

反向限制：不要完整地图、背景图、面板、按钮、卡片、文字、数字、标题、星星数量、进度条、奖励物、现实角色、logo、屏幕截图、商标。状态之间不暗示具体玩家进度或服务数据。
