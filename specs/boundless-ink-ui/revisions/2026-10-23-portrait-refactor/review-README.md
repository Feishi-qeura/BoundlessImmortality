## 设计选择

推荐“克制水墨修仙”：沿用背包与角色页的墨边、宣纸、书法，以青玉区分状态、旧金强调主操作；HUD使用局部墨底，功能页使用单层纸底。这样能与三个保留面板衔接，也能让竖屏正文保持清楚。

另外两种方向是“重金传奇”（装饰更强、容易挤占阅读区）和“纯素水墨”（更清淡，但与现有金边背包/排行榜衔接较弱）。当前候选采用推荐方向，尚未把个人选择登记成用户批准。
