# 武灵山门 Widget 实现

2026-10-23。新增 `UInkWulingSectPanel`，仅拥有自己的 `Frontend/UI/InkWulingSectPanel.h/.cpp`，由主实现将 `Wuling` 路由指向此类，原世界准备面板经 `WulingWorld` 路由继续使用。

- 继承现有 `UInkFeaturePanel` 和统一可滚动水墨外壳，复用青云山场景。窄屏单列；有效正文宽度达到 800 且为横屏布局时采用等宽两列，各栏按实际正文宽度计算，正文由外壳单一滚动区域承载。
- 山门显示权威 guild.name、公共资材 supply、声望 reputation；正式成员 members、参与成员 participating_members、临时助战 helpers 分别显示。无数据使用破折号，真实零保持为零；断线保留快照时明确标注“上次同步”。
- 名册预览仅取服务 members 当前页前四条及真实 member_cursor，不编造成员；空页与未同步状态分别说明，并进入现有 WulingGuild 完整名册/组织管理。
- 创建名称输入框通过 `InkUiTypography::MakeFont(Body, 28)` 使用正文契约。创建动作须同时满足服务启用、已连接、非忙碌、已有快照、尚无 guild；仅清理输入首尾空白和拦截空名，正式名称规则仍由服务校验。只调用现有 `CreateGuild`，不新增成长或经济规则。
- 链接门派建设、剑灵权益、装备成长、离线记录、订单，以及仙途地图与世界历练准备/进度。离线浏览入口可用，但此面板不提交写操作。
- `RefreshLiveData()` 使用组织、人数、名册预览、服务状态和区域阶段键；忽略全局版本、服务器时钟、钱包等无关变化。刷新仅原位更新文本/按钮状态，不重建 Widget、不覆盖正在编辑的名称；真实尺寸变化导致外壳重建时先保存草稿。
- 内置 `Boundless.InkUI.WulingSect.SnapshotIsolation` 自动化，验证无关快照变化不使编辑器失效、未知/零资材区别、助战人数与正式成员分离、真实名称变化、未同步/空快照区别。

## 验证边界

本子任务只执行静态源码与布局数值检查，未运行 Editor build、自动化或 PIE。父实现负责注册路由、HUD 接入、统一编译与运行上述自动化，以及 720×1280 / 1280×720 渲染和 Slate 点击验证。现有场景是复用的青云山插图，并未新建游戏场景、山门世界资产或虚构门派成员。

静态几何检查结果：720×1280 正文宽 608，单列，双按钮各宽 298；1280×720 正文宽 1116，双列各宽 546，双按钮各宽 267；390×844 正文宽 278，单列，双按钮各宽 133。按钮高均为 88。源码契约检查确认公开 RefreshLiveData override、面板无 RebuildPanel 调用、包含 SnapshotIsolation 自动化。几何数值检查不等同于实际渲染/文字测量。
