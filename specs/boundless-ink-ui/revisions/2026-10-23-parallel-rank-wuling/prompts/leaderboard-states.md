# 排行榜候选页面提示词

共同基线：720×1280 竖屏，SafeZone 后四边24单位；沿用水墨纸色、墨山淡边、旧金克制点睛，正文/数字霞鹜文楷，标题马善政体；固定页头和底部我的位置，中段独立滚动。三类使用同一结构、分别独立生成。不得使用项目本地图像或其他游戏原图。AI中文字需人工校对，候选未批准。

## 伤害榜
原创修仙手游榜单 UI。天下榜，伤害榜选中；周期本周；三名角色排行，头像、名次、姓名、伤害值分列；底部显示我的排名及服务可领取奖励按钮。纸墨山水轻装饰，信息清晰。

## 修炼速度榜
同一套天下榜页面，修炼速度选中；指标按服务字段显示“修炼速度”和其真实单位占位，不出现伤害或战力。榜单行与固定我的排名位置相同；周期、规则入口保留。

## 主播剑灵榜
同一套天下榜页面，主播剑灵选中；主体标签明确写“主播剑灵”，头像/名称及服务提供的榜单指标单独呈现，不合并主播数据，不自行构造总战力。奖励与我的位置仍由服务状态决定。

## v2 修订提示词（视觉 QA 后）

v1 保留原样；v2 独立文件。共同要求：删除虚构人物姓名、名次数值、未证实单位、奖励领取按钮；榜单三页统一构图。仅显示“名次字段 / 身份字段 / 指标字段”占位；底部本人状态展示“未上榜 / 无数据”。

### 伤害榜 v2
天下榜，伤害榜选中，另有修炼速度/主播剑灵切换。简洁统一的宣纸墨山版式，表格列为名次字段、身份字段、伤害字段，不显示行数据、不编造姓名或数字。空态写“暂无数据”；固定本人条写“我的排名：未上榜 / 无数据”。不显示奖励、领取 CTA。

### 修炼速度榜 v2
与伤害榜完全相同的页面布局和密度，修炼速度选中；表格列名使用修炼速度字段占位，不写单位或数值；空态“暂无数据”，本人条“未上榜 / 无数据”，无奖励按钮。

### 主播剑灵榜 v2
同一布局，主播剑灵选中并明确其为榜单对象；仅用榜单对象字段与榜单指标字段占位，不填主播名、剑灵名、战力或数值。空态和本人状态同其他榜单，无领取按钮。
