# 竖屏 UI 套件扩展计划

> **执行者说明：**按本计划逐阶段完成 GameUI 文档与视觉交付；每阶段只在自己的审阅条件满足后进入依赖阶段。

**目标：**以已批准的完整设计为基线，补齐并交付 BoundlessImmortality 的竖屏修仙 UI 规范、逐页状态契约与可复现页面原型。

**架构：**沿用 `specs/boundless-ink-ui` 的已批准策划、页面 ID、路由和样式契约；将任何变更写入本项目 specs，页面生成按信息依赖分批，突破 UI 字段读取现存 v1.4 权威表，不复制创建数值公式。

**技术栈：**GameUI 项目模板与验证器、YAML/Markdown 契约、ImageGen 页面原型；最终目标 Unreal Engine 5.8，交付通用设计契约与素材，不生成原生 UMG/uasset。

**设计依据：**`revisions/2026-10-23-full-portrait-suite-design.md`

## 全局约束

- 主审竖屏逻辑画布为 720×1280，横屏按 1280×720 信息重排。
- 延续项目水墨风格；标题马善政体，正文及数字霞鹜文楷，术语使用“血量”。
- 保留主菜单、HUD、角色属性主面板与背包既有结构；不覆盖场景或玩法蓝图。
- 主播、观众剑灵、武灵集体三个数据主体区分展示；武灵是组织，不是宠物。
- 商店、签到、贡献榜、突破和天劫数据必须来自权威状态；没有开放能力时按功能开关隐藏或禁用。
- 不使用本地图片作为参考；线上案例只提供布局研究，不复制受保护角色、商标或完整页面。
- 未经用户审阅的页面图与资源保持 `approved: false`；未验证的平台能力不声称已完成。

## 重点检查输入

- 窄屏/刘海安全区与长中文标签：测试三种逻辑视宽，保证主按钮、底导航和 HUD 不遮挡且可触达。
- 活动结束/时区与设备时间漂移：显示服务端时间戳和活动状态，不用客户端时钟判定结果。
- 榜单空值、未上榜、并列和分页：明确周期、单位、排名与自己的位置，不拼合不存在的战力字段。
- 突破配置缺失或分值异常：渲染明确不可突破状态，材料来源和倍率由权威配置驱动，不静默套默认奖励。
- 页面功能关闭但路由被直达：展示不可用处理并保持返回，不泄露隐藏的购买/活动能力。
