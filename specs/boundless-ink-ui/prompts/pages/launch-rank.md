# 开服贡献榜

## 页面定位
显示活动周期内的有效贡献排行榜和玩家自己的位置，不用伤害、礼物金额或虚构战力代替贡献。

## 视觉约束
沿用水墨排行榜样式，正文清晰、窄屏行高可读、金色仅用于前三名或本人标记；排行榜对象与个人身份字段分开。

## 布局与组件
顶部返回、活动名、服务端周期/更新时间；中部排行行显示名次、头像占位、名称、有效贡献分；底部固定“我的贡献/我的排名”卡片。并列名次和超过榜单范围未上榜需有文本状态。

## 状态
加载、空榜、正常、并列、未上榜、断线旧快照、结算锁定和功能关闭。

## 图像生成提示词
Create one portrait 9:16, 720x1280 clean leaderboard mockup for a Chinese xianxia mobile RPG launch event. Match the approved ivory-paper, ink-green and muted-jade style with restrained antique-gold rank accents. Show a fixed back/title header, a clearly labelled blank event period and updated-at line, a scrollable ranked list with rank, avatar placeholder, player name placeholder and contribution score placeholder, plus a persistent bottom “my contribution / my rank” card. Provide a visually clear tie marker and a separate not-ranked/empty-state panel variant area. Every column should have room for real text; use placeholders rather than invented names or scores. Orthographic UI, large touch targets, no phone frame.

## 反向限制
No damage ranking, gift money, total combat power, fake names/scores, gold-heavy decoration, color-only rank meaning, unreadable rows, gibberish, logo, watermark, or local screenshot reference.
