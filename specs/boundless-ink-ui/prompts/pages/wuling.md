# 武灵

## 页面定位
主播创建并命名的协作组织总览，清楚区分组织进度与主播/观众的个人修为。
## 视觉约束
沿用组织 page family 的徽记、宣纸卡、青玉状态与旧金主行动。
## 布局与组件
顶部武灵名称与组织徽记；核心区主播身份、成员数、共同进度；中部成员行含头像占位、剑灵身份和个人贡献；底部建设、成员、记录入口。
## 状态
未加入/无成员/权限不足/请求中/网络断开；组织进度无数据时不填充。
## 图像生成提示词
Create a 9:16 portrait Chinese xianxia game organization overview called Wuling. Refined warm paper and ink-green UI consistent with a premium ink-wash mobile game. Show a simple organization seal and name header, a distinct anchor/leader profile card, collective guild milestone progress, a clean member list with avatar placeholders and concise contribution chips, and a bottom row of organization actions. Ensure the visual distinguishes the organization collective from individual viewer sword spirits. Clear blank text areas for later typesetting, light jade separators, sparse antique-gold focus, generous mobile-safe spacing, no phone frame.
## 反向限制
武灵不可画成宠物、召唤兽或宗门门派；个人境界不能与集体等级合并；不显示捐赠氪金或未定义排名。
## 验收记录
候选待审，权限和成员信息来自 GuildVm。
