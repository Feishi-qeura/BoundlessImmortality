# 排行榜

## 页面定位
在伤害、修炼速度、主播剑灵三类排行间切换，快速看规则、周期、自己位置。
## 视觉约束
沿用项目水墨纸面和字阶，榜单优先数据可读；榜首可用轻量徽记，不用金色铺满。
## 布局与组件
顶部标题与周期；三段式类别切换；周期/单位说明；榜单列表列出名次、头像占位、名称、指标；底部固定“我的排名/未上榜”。
## 状态
默认榜单、空榜、未上榜、并列、刷新中、断线显示上次更新时间。
## 图像生成提示词
Portrait 9:16 Chinese xianxia game leaderboard UI, warm ivory xuan paper, deep ink green, jade dividers, restrained antique gold. A clean top title/back row, three compact category tabs labeled damage, cultivation speed, anchor sword spirits (legible Chinese if possible, otherwise blank type areas), visible period selector and unit note, readable list rows with rank/avatar/name/value, elegant small top-three markers, fixed self-rank strip at bottom. Accurate straight-on mobile interface with safe areas; maintain ink design consistency, clear typography scale and generous row spacing. No full-screen gold, no fake numeric claims, no imported game logos or local reference screenshots, no gibberish text.
## 反向限制
不合并三类指标、不展示未定义战力、不隐藏周期单位、不把礼物金额转换为榜分。
