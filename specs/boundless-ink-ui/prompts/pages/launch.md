# 开服活动

## 页面定位
限时开服活动总览，承接活动剩余时间、每日任务、贡献进度、里程碑和获准特惠 SKU。

## 视觉约束
沿用项目水墨规范，不使用促销电商金红风。倒计时取 server_utc；只有服务提供有效 SKU 且购买能力开启时才出现购买 CTA。

## 布局与组件
页头显示返回、活动名与服务端倒计时；上段为个人贡献/里程碑进度；中段为每日任务清单与完成状态；下段为贡献榜入口和特惠商品卡，价格/库存/按钮仅给权威数据留位。没有 SKU 时隐藏购买卡或显示未开放说明。

## 状态
未开放、进行中、即将结束、已结束、任务空/完成/处理中、SKU 关闭/售罄、断线快照与领取失败。

## 图像生成提示词
Create one portrait 9:16, 720x1280 xianxia mobile RPG limited launch-event page mockup, matching the approved restrained ink-and-paper UI. Use warm ivory surfaces, ink-green text, muted jade dividers and small antique-gold highlights, not a loud red sale page. Layout: fixed back/title header with a blank server-driven countdown; a compact contribution progress and milestone panel; a scrollable daily-task list with clear task state/check affordance; a contribution leaderboard entry; and a small special-offer area with blank SKU, price, stock and purchase-status fields that can be hidden when disabled. Fixed bottom CTA is for an available task/claim only, never an invented purchase. Keep all dynamic text/value regions blank for engine typesetting, clear touch targets and safe area, no phone frame.

## 反向限制
No fabricated countdown, price, discount, stock, payment success, daily progress or rank. No purchase CTA if SKU capability is disabled. No local image reference, casino motifs, aggressive sale stickers, unreadable/gibberish text, logos, watermark, or clutter covering task status.

## 验收记录
待生成/待审；商品能力与价格字段由服务开关/权威 SKU 决定。
