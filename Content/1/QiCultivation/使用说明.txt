七灵真气 V2 使用说明

一、编辑器中预览与预制
打开 BP_TopDownCharacter，选中组件 QiCultivation，在“修炼 > 预览”勾选“编辑器预览”。当前角色默认已勾选。
切换到蓝图“视口”，打开实时更新（Ctrl+R）。无需开始游戏或点击模拟。
关卡中放置带该组件的角色也可预览，同样需要关卡视口实时更新。
“应用真气配置”保持当前粒子，“重新开始预览”清空后重新生成。关闭“编辑器预览”会清理光球及临时描边。
预览开关仅影响编辑器；游戏开始时默认关闭修炼，仍按 C 切换。

可复用组件预设：/Game/1/QiCultivation/BP_QiCultivationPreset
这是 QiCultivationComponent 的组件蓝图子类，可在其类默认值保存配置，再通过角色的“添加组件”添加。一个角色保留一个修炼控制组件。
现有 BP_TopDownCharacter 继续使用原 QiCultivation 组件，属性和接口相同。

二、直接在组件 Details 调参数
“真气配置”中有 白·炼气 / 红·火 / 绿·风 / 黄·土 / 蓝·水 / 青蓝·冰 / 紫·雷，各自包含：
- 每轮数量：0～64，按汇聚时长分散生成；0 停止后续生成，现存光球继续汇聚消失。
- 生成半径：20～2000cm；生成于该半径的 65%～100% 环带。
全局：汇聚时长 1～20秒，生成高度 0～1000cm，光球尺寸 8～120cm。
“描边”中有：
- 火焰外扩大小：0～12cm，真正改变覆盖材质的几何外扩幅度。
- 描边宽度：0.05～3，改变轮廓光覆盖宽度。
- 微光强度：0～5，0 隐藏描边。
- 火焰流动速度：0～5，0 冻结材质流动。
这些属性保存到组件/蓝图，不再要求先进入游戏才能配置。
该组件上的配置为当前角色的参数来源；直接播放 NS_QiCultivation 时仍使用 Niagara User Parameters。

三、蓝图调整小球数量
从组件 QiCultivation 引用拖线，搜索“设置真气数量”（英文 Set Qi Count）。
Element 下拉框选择灵根，例如 水；Count 输入所需数量，例如 20。不会修改其他灵根。
同样提供“获取真气数量”“设置真气范围”“设置修炼描边”，以及 Start Cultivation / Stop Cultivation / Toggle Cultivation。
旧 Configure Qi(Type,Count,Range) 仍兼容：Type=0白/1火/2风/3土/4水/5冰/6雷。
设置数量/范围可在 Construction Script、BeginPlay 或运行时调用。直接 Set 结构体属性后调用“应用真气配置”。
BP_QiCultivationPreset 内 Example_SetWaterCount 函数提供实际连线示例。
数量是每轮目标值，并非强制立即生成/删除的硬上限；Live Counts 显示真正存活数量。描边颜色按 Live Counts 分配，等比时保留七彩。
这些接口只控制本地视觉，不执行 RPC、经验或属性修改。

四、形态
白：柔和不规则淡雾。土：不规则土黄色矿石碎块和薄尘。
水：蓝色水滴主体加少量底部涟漪。冰：每个光球不同的随机冰片尺寸、方向和位置。
雷：真实球体 Mesh Renderer 上的立体电弧，随视角产生前后层次；材质 M_QiLightning3D。
M_QiOrb 是共享母材质，缩略图是中性占位核心，不是额外的第八类真气。
