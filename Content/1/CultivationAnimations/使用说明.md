# SK_Mannequin 修炼与单膝攻击动画（FBX 替代版）

当前六段资产已使用用户提供的 `exported-model.fbx` 替代：`Meditate` 用于盘腿修炼，`Kneeling_Tired` 按用户指定作为单膝跪地攻击动作。
源 FBX 的两段动作保存在 Blender 中，原来的合掌版本也保留了备份。

六段动画均为 30 fps，直接使用现有骨架：
`/Game/Guard/Demo/ThirdPerson/Characters/Mannequins/Meshes/SK_Mannequin`。
预览网格为角色蓝图实际使用的 `SKM_Quinn_Simple`。

| 动画 | 时长 | 用途 |
| --- | --- | --- |
| A_Meditation_Start | 2.4 秒 | 站立 → 盘腿漂浮，双手放膝 |
| A_Meditation_Loop | 4 秒 | Meditate 重定向循环，保留呼吸并增加轻微漂浮 |
| A_Meditation_End | 2.4 秒 | 展腿落地、回到待机站姿 |
| A_Charge_Start | 1.2 秒 | 站立 → 单膝攻击姿势，含前脚抬脚轨迹 |
| A_Charge_Loop | 2 秒 | Kneeling_Tired 重定向的单膝攻击循环 |
| A_Charge_Release | 1.2 秒 | 结束单膝动作，返回待机站姿 |

两个 Loop 的首尾姿势一致；Start 的末帧与 Loop 首帧一致，Loop 末帧与 End/Release 首帧一致。
源骨架为 67 根骨骼，目标预览骨架为 88 根骨骼；按关节方向及弯曲平面重定向，并根据目标身材调整手腕与膝盖的相对位置。进入/退出额外检查了蒙皮网格的地面穿插和前脚支撑。

## 使用

在 AnimBP 状态机或 Montage 中按 Start → Loop → End/Release 播放。只有 Loop 段应开启循环。
Root Motion 关闭，root 无位移；漂浮由骨盆及腿部动画实现。不要在盘腿期间启用站立用的脚底 IK。
从 Loop 中途退出时应使用短混合过渡（约 0.15–0.25 秒），因为呼吸/漂浮高度随循环相位变化。
六段动画已通过 `CultivationGameplay` 组件绑定到 `BP_TopDownCharacter`，在 `Level_Sky_Temple_Demo_01` 中对实际控制的角色生效。

| 操作 | 行为 |
| --- | --- |
| W / S / A / D | 按相机方向移动，斜向速度保持一致 |
| 长按 C 约 0.35 秒 | 进入修炼：开始 → 循环；持续按住只触发一次 |
| 松开 C 后，再次长按 C | 退出修炼：结束 → 恢复移动 |
| 按下 / 持续按住鼠标左键 | 进入单膝蓄力，开始动画之后持续循环 |
| 松开鼠标左键 | 播放蓄力结束动画，恢复移动 |

修炼与蓄力互斥，开始、循环和结束期间都锁定移动。开始动画尚未播完时请求退出，会在到达对应姿势后播放结束动画。鼠标左键不再点击寻路。

角色仍由隐藏的 `CharacterMesh0`（SK_Mannequin）驱动可见 Guard；动作结束后恢复原 `ABP_Unarmed` 行走动画蓝图。修炼调用已有 Qi 修炼特效，其他关卡保留原输入。
在角色蓝图中选择 `CultivationGameplay` 组件，可修改六段动画引用及 `Hold Toggle Seconds`。运行逻辑位于 `Source/BoundlessImmortality/CultivationGameplayComponent.cpp`。

`L_CultivationPreview` 是独立姿势检查关卡，六个人形分别固定在各段的代表时间点；打开单个 AnimSequence 可完整播放。
